# Market - A reference Interface for Joint

The `market` repository provides an easy to use web interface for accessing Joint protocol functions. The goal of this repositoty is create a base interface for Joint protocol. Developers can building on top of this repository to create their own applications or use it as a reference for their own Joint-focused projects.

## Installation

Clone the repository and run the following command to install the dependencies:

```bash
yarn install
```

## Development

Run the command below to start the development server:

```bash
yarn dev
```

## Build

Run the command below to build the application for production:

```bash
yarn build
```

## Configuration

Rename the `.env.example` file to `.env` and fill in the values.
